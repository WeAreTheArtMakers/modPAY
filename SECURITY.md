# Güvenlik bildirimi / Security policy

Bir güvenlik açığı bulduysanız lütfen herkese açık bir issue açmayın; **admin@wearetheartmakers.com** adresine yazın. WATAM bildirimi 2 iş günü içinde değerlendirir, ciddiyetine göre yama ya da geçici önlem yayımlar ve etkilenen müşterileri doğrudan bilgilendirir.

If you find a vulnerability, please do not open a public issue; write to **admin@wearetheartmakers.com**. WATAM assesses reports within 2 business days, ships a patch or mitigation according to severity and informs affected customers directly.

modPAY şu an **yalnızca test ağlarında** (testnet) kullanım içindir; bağımsız bir güvenlik denetiminden geçmemiştir ve gerçek değerli varlıklarla kullanılmamalıdır. / modPAY is currently **testnet-only**; it has not had an independent security audit and must not be used with assets of real value.
